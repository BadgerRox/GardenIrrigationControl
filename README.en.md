## ✨ Features

Intelligent sequence control for multiple irrigation zones: Dynamically calculates the exact water requirement based on temperature, sunlight, wind, and humidity—ensuring targeted watering without wasting water.

## 🛠️ Installation

Via the IP-Symcon **Module Store**:
1. Open the IP-Symcon management console.
2. Navigate to the **Module Store** and search for `Garden Irrigation Control`.
3. Click on **Install**.

Alternatively, install manually via the *Modules* core instance:
`https://github.com/BadgerRox/GardenIrrigationControl`
