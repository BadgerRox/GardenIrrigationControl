## ✨ Funktionsumfang

Intelligente Ablaufsteuerung für mehrere Bewässerungszonen: Berechnet den exakten Wasserbedarf dynamisch anhand von Temperatur, Sonne, Wind und Luftfeuchtigkeit – für eine zielgerichtete Bewässerung ohne Wasserverschwendung.

## 🛠️ Installation

Über den IP-Symcon **Module Store**:
1. Öffne die IP-Symcon Verwaltungskonsole.
2. Navigiere zum **Module Store** und suche nach `Garden Irrigation Control`.
3. Klicke auf **Installieren**.

Alternativ manuell über die Kern-Instanz *Modules*:
`https://github.com/BadgerRox/GardenIrrigationControl`
